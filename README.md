# Gacha AI — gacha-game 원본 기반

기존 gacha-ai 게임과 화면을 교체했습니다. [gacha-game](https://github.com/y3ssam/gacha-game)의 원본 HTML 구성·전체 CSS·전체 에셋을 기반으로, 미리보기였던 게임 기능을 실제 플레이와 저장으로 연결한 버전입니다. 원본의 사이드바·7단계 세계 생성·하단 5개 메뉴·6인 전열/후열·캐릭터 상세 7개 탭·장비 6부위·대화/전투 화면을 사용합니다.

## 실행

Node.js 22 이상에서 저장소 폴더의 `npm start` 또는 Windows의 `start-local.cmd`를 실행하고 표시된 로컬 주소를 엽니다. 기본 포트는 4173이며 이미 사용 중이면 4174부터 최대 20개 포트 중 빈 포트를 찾아 실행합니다. 실행 창의 `Local:` 주소를 여세요. PORT 환경 변수를 직접 설정하면 해당 포트만 사용합니다. npm install이나 빌드는 필요하지 않습니다.

1. **AI 연결**에서 Vertex 서비스 계정 JSON과 모델·리전을 저장합니다. 이미지는 NovelAI 연결도 저장합니다. 원본의 Windows DPAPI 암호화 연결 저장·수정·테스트·이미지 옵션을 그대로 사용합니다.
2. **세계관 → 세계관 추가**에서 7단계를 작성합니다. 로어북의 배경·주인공·등장인물을 선택할 수 있습니다.
3. **세계 생성**을 누르면 세계 설정 → 캐릭터 8명 → 4챕터씩 3묶음(12챕터 × 10화)을 검증·저장합니다. 실패하면 세계 목록의 **생성 이어하기**로 저장된 단계부터 재개합니다. 새 세계에는 생성 전 인물이나 예시 이야기가 없습니다.
4. 생성된 동료 6명이 초기 편성됩니다. 원본 편성 화면에서 드래그하거나 슬롯·캐릭터를 눌러 전열/후열을 바꿀 수 있습니다. 편성 추가·이름 변경·삭제도 저장됩니다.
5. **전투 → STORY**에서 첫 입장에 시나리오를 생성합니다. 저장된 대사·선택·요약을 다음 생성에 전달합니다. 대화 완료 → 선택 → 편성 → 브리핑 → 전투 시작 순으로 진행합니다. 읽기만으로 클리어되지 않습니다.
6. **MATERIALS**에서 골드·성장·장비·속성 스킬/돌파 던전을 플레이합니다. 층 클리어·보상·장비·성장은 저장됩니다.

## 연결된 기능

- 원본 UI의 캐릭터 검색/역할·속성 필터/정렬, 정보·장비·스킬·각성·의상·호감도·프로필.
- 6대6 속도 순 전투, 기본·액티브·궁극기·패시브, HP·에너지·쿨타임·회복, 원본 장비 2/4세트 및 확률 효과, 자동/배속/퇴각/이어하기, 승패·1회 보상·시나리오 해금.
- 소환 1/10회, 다이아 차감, 5성 2%/4성 13%/3성 85%, 90회 5성 및 10회 4성 이상 보장, 중복 각성(최대 10), 출현 목록·기록. 확률은 이 게임에 추가한 규칙이며 원본 미리보기의 기존 수치라고 주장하지 않습니다.
- 최대 Lv.100, 20레벨마다 돌파(최대 4), 원본 무작위 4종 스킬 강화(최대 Lv.10), 장비 +15·부위/클래스/세트/장비 이전.
- 원본 이미지 108장(장비 60장 포함), 전체 assets 파일 121개를 원본 그대로 복사했습니다. [원본 해시](docs/IMPORTED-ASSETS.json).
- 설정한 이미지 종류와 크기를 사용한 배경·캐릭터·적·전투 배경·CG·배너·의상 생성. 인물은 NovelAI 개별 캐릭터 칸에 전달합니다. 의상은 고정 외형과 별도 의상 태그를 합칩니다. 실패한 이미지는 세계관의 **이미지 생성 기록**에서 직접 재시도합니다. 실패 시 기존 이미지는 보존합니다.
- 호감도 3/6/9 스토리 AI 생성과 캐시, 로어북 생성 지침 반영.

## 저장·키·호환성

게임 세계·지침·진행은 브라우저 IndexedDB에 저장합니다. 이미지는 별도 저장소에 보관해 매 전투 행동마다 이미지 전체를 다시 쓰지 않습니다. **세계관 → 현재 세계 내보내기 / 저장 가져오기**로 이미지 포함 백업을 옮길 수 있습니다. 연결 키와 토큰은 게임 백업에 들어가지 않습니다.

원본의 연결 키 저장 위치는 Windows 현재 사용자 DPAPI로 암호화한 `%LOCALAPPDATA%/GachaGame/connections.dpapi`입니다. 서비스 호출은 PC의 루프백 서버에서 고정 Google/NovelAI 주소로만 보냅니다. 원본 연결 테스트는 유료 API를 호출할 수 있으며, 게임 생성과 이미지 생성에도 이용량이 발생합니다. 계정 권한·결제·모델 접근은 본인 계정에서 설정해야 합니다.

새 게임 형식은 v2이고 브라우저 DB는 `gacha-game-worlds`입니다. 기존 gacha-ai v1 DB는 삭제하거나 덮어쓰지 않으며 새 6인 게임에 자동 변환하지 않습니다. 주소/브라우저가 바뀌면 저장 영역도 달라집니다.

GitHub Pages에서는 정적 화면과 이미 생성된 저장을 사용할 수 있습니다. 실제 AI 연결·DPAPI 저장·생성은 `npm start`로 연 PC 로컬 주소에서 사용합니다. 이 작업은 Pages 설정·공개 배포를 변경하지 않습니다.

## 검증

`npm run check`, `npm test`를 실행합니다. Windows DPAPI 검사는 같은 Windows 사용자 권한이 필요합니다. 원본 연결/이미지/장비/에셋 검사에 6인 엔진·AI 생성 단계 재개·시나리오 캐시·유료 이미지 재시도·실제 원본 전투 DOM 검사를 추가했습니다. 실제 브라우저에서 저장 가져오기·성장·시나리오·선택·편성·전투·배속·새로고침 복원을 확인합니다.

실제 계정의 Vertex/NovelAI 유료 생성은 이 작업에서 실행하지 않았습니다. 모의 응답 테스트가 모델 권한·품질·실제 비용을 보증하지 않습니다. 장기 밸런스 검증도 별도입니다.
