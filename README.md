# Gacha AI

사용자 지침으로 세계·캐릭터·시나리오를 생성하는 로컬 저장 싱글 플레이 가챠 RPG입니다. 브라우저 게임과 PC용 AI 연결 프로그램이 함께 들어 있습니다. 전투·확률·성장·보상은 고정 게임 엔진이 처리합니다. 최초 세계·캐릭터 생성에는 Vertex AI 연결이 필요합니다.

## 바로 실행

1. 이 저장소를 다운로드하거나 clone합니다.
2. [Node.js](https://nodejs.org/) 22 이상을 설치합니다.
3. 저장소 폴더에서 실행합니다.

```bash
npm start
```

4. 터미널의 `http://127.0.0.1:8787`을 엽니다. 별도 `npm install`은 필요 없습니다.
5. 빈 새 게임 화면에서 AI를 연결하고 지침을 입력한 다음 세계를 생성합니다. 기본 제공 세계나 캐릭터는 없습니다.

Windows에서는 `start-game.bat`을 실행해도 됩니다. 종료는 터미널에서 Ctrl+C.

## 내 지침으로 생성

1. **설정 → AI 연결**에서 터미널의 연결 코드, Vertex 서비스 계정 JSON 파일, NAI Persistent API Token을 입력합니다. 모델 ID와 리전도 변경할 수 있습니다.
2. **설정 → 새 세계 → 지침으로 생성할 빈 세계**를 선택합니다.
3. **지침**에서 전체 / 세계관 / 가챠 / 장면 / 챕터별 / CG / 캐릭터 스토리 지침을 입력하고 저장합니다. 주인공·고정 설정은 세계관 지침에 작성합니다.
4. **세계 · 캐릭터 생성**을 실행합니다. 세계 규칙 → 8명 캐릭터의 고정 외형 → 기본 의상 → 6종 적 도감 → 12챕터/36화 설계 → 픽업 배너 순서로 생성합니다. 각 단계는 검증·저장되며 실패한 단계부터 재시도합니다.
5. 시나리오의 각 화에 처음 입장할 때 해당 내용을 생성합니다. 읽은 내용의 요약과 선택지는 다음 생성에 전달됩니다.
6. 캐릭터 상세에서 **캐릭터 스토리**를 읽을 수 있습니다. 유대 5마다 새 이야기가 생성됩니다.

**이미지 자동 생성**을 켜고 NAI를 연결하면 세계 생성 시 로비·초기 파티·픽업 배너를, 첫 시나리오 입장 시 배경·CG·적 이미지를 생성합니다. 소환으로 새로 만난 캐릭터도 일러스트를 생성합니다. 개별 일러스트/배너 생성 버튼과 설정의 이미지 기록에서 재생성할 수 있습니다. 호출은 사용자 조작에 의해 시작되며 자동 재시도로 이용량을 소모하지 않습니다.

Vertex 계정에 결제·Vertex AI API·서비스 계정 권한이 필요합니다. 기본 모델은 `gemini-2.5-flash`, 리전은 `global`이며 계정에서 사용할 수 있는 모델 ID로 바꿀 수 있습니다. NovelAI 기본 모델은 `nai-diffusion-4-5-full`이며 Persistent API Token과 해당 이용 권한·Anlas가 필요합니다. 연결 설정 성공은 로컬 메모리에 설정이 전달되었다는 뜻이며 실제 모델 권한 검사는 생성할 때 수행됩니다.

## 캐릭터 이미지 구분

캐릭터의 성별·성숙도·피부·체형·머리 길이/모양/앞머리/색·눈 모양/색·고유 특징을 NAI용 외형 항목으로 저장합니다. 기본 의상과 가챠 의상은 별도 프롬프트로 생성하고 이미지 생성 시 해당 인물의 외형과 합칩니다.

여러 인물이 나오는 CG·배너는 각 인물 ID와 위치를 지정하고 **NAI의 개별 캐릭터 프롬프트 칸**으로 전송합니다. 공통 칸에는 배경·조명·스타일만 넣으며 인물별 부정 프롬프트도 분리합니다. 인물 이미지는 NAI V4 이상, 게임 내 최대 6명입니다. 지원하지 않는 모델에서 혼합 프롬프트로 대체하지 않습니다.

캐릭터 상세에서 **NAI 외형 · 기본 의상 프롬프트**를 확인할 수 있습니다. 기존 AI 캐릭터는 다음 생성 또는 보강 버튼에서 분리하며 획득 이미지와 진행은 유지됩니다.

## 이벤트·신규 풀·의상

- **이벤트**: 14일 시즌의 3×3 미션 빙고, 20레벨 시즌 패스, 이벤트 던전, 재화 교환소와 보급 뽑기를 제공합니다. 종료 후 3일은 보상 수령·교환 정산 기간입니다.
- **주기 콘텐츠**: Vertex가 연결된 열린 게임에서 7일 주기로 신규 5/4/3성 각 1명과 픽업 배너를 추가합니다. 지침 화면에서 자동 갱신을 끌 수 있으며 소환 화면에서 수동 생성·실패 재시도가 가능합니다. 기존 인물과 소환 보장은 보존됩니다.
- **의상 가챠**: 플레이어 Lv.5에 보유 캐릭터 2~3명이 고정 추첨됩니다. 소환의 의상 탭에서 Vertex/NAI로 추가 일러스트 풀을 준비한 뒤 소환합니다. 기본 10%, 10회 이내 미획득 의상 보장, 1회 성정석 120 또는 의상권 1장입니다.
- **이미지 선택**: 캐릭터 상세의 보유 일러스트에서 기본/획득 의상을 선택할 수 있습니다. 로비·편성·전투에 반영되며 스탯은 동일합니다.
- 이전 저장은 캐릭터·재화·천장을 유지하며 확장됩니다. 기존 승리/시나리오 기록에서 초기 플레이어 XP도 반영합니다.

자동 갱신은 **앱이 열려 있고 Vertex가 연결되어 있을 때** 동작합니다. 닫혀 있는 동안 API를 호출하지 않으며 누락 주기를 한꺼번에 유료 생성하지 않습니다. NAI 이미지는 실제 게임 조작에서 생성합니다.

[이벤트·의상 상세 규칙](docs/LIVE-SYSTEMS.md) · [AI 코드 자체 검토와 개선](docs/AI-REVIEW.md)

## GitHub Pages

프런트엔드는 정적 파일이며 `/gacha-ai/` 하위 경로를 지원합니다.

- 간단한 방법: 저장소 **Settings → Pages → Deploy from a branch → main / (root)** 선택.
- Actions 방법: **Settings → Pages → GitHub Actions**를 선택하고 **Actions → Deploy GitHub Pages → Run workflow** 실행. 배포 아티팩트에는 게임 정적 파일만 포함됩니다.
- 사이트 주소는 설정 후 `https://y3ssam.github.io/gacha-ai/`입니다. 이 변경에서 Pages를 활성화하거나 배포하지는 않았습니다.
- AI를 사용할 때는 PC에서 `npm start`를 계속 실행하고 Pages의 설정에 연결 코드를 입력합니다. 브라우저의 로컬 네트워크 접근 요청은 허용해야 합니다. 차단되는 브라우저에서는 로컬 주소로 플레이하세요.
- Pages 자체는 Node 서버를 실행하지 않습니다. 현재 AI 연결은 **로컬 연결 프로그램이 실행 중인 PC**를 대상으로 합니다. 모바일 단독 AI 생성이나 원격 공유 프록시는 구현 범위에 포함되지 않습니다. AI 없이 기존 생성 콘텐츠를 플레이하는 것은 가능합니다.

## 저장과 개인정보

- 계정/로그인/멀티플레이/중앙 게임 데이터 서버가 없습니다.
- 진행 데이터·지침·콘텐츠·이미지는 브라우저 IndexedDB에 저장됩니다. 이미지와 진행 메타데이터는 별도 저장소에 보관해 전투마다 이미지를 다시 쓰지 않습니다.
- **설정 → 현재 세계 내보내기 / 저장 파일 가져오기**로 이미지가 포함된 JSON 백업을 옮길 수 있습니다. 브라우저 데이터 삭제 전에 내보내세요.
- 로컬 주소와 Pages 주소는 저장 영역이 다릅니다. 두 주소 사이에서도 내보내기/가져오기를 사용하세요.
- JSON 키·NAI 토큰·OAuth 토큰은 로컬 프로그램 메모리에만 존재하며 프로그램 종료 또는 연결 해제로 폐기됩니다. 저장 파일이나 저장소에 포함되지 않습니다.
- API 호출 시 해당 서비스로 지침과 필요한 콘텐츠가 전송됩니다.
- GitHub 공개 저장소는 의도한 설정입니다. 사용자별 키와 세이브는 여기에 저장되지 않습니다.

## 개발 검증

```bash
npm run check
npm test
```

Node 내장 테스트로 기간 경계·정산·중복 보상·시즌 전환·의상 보장/비용/선택·AI 단계 재개/참조·이전 저장 이행과 소환 보장, 재화 원자성, 성장 상한, 전투 종료와 중복 보상 방지, 장비, AI 응답 규격, JWT 서명, NAI 요청/ZIP 해제, 로컬 연결 보안을 검증합니다. 실제 API 키를 사용하는 유료 호출 테스트는 포함하지 않습니다.

## 게임 화면

게임은 중앙의 **1600×900** 프레임 안에서 실행되며, 바깥 여백은 밝은 회색입니다. 작은 창에서는 프레임 전체가 16:9로 축소됩니다. 긴 목록과 설정은 게임 화면 내부에서 스크롤합니다. 휴대폰에서는 가로 방향을 권장합니다. UI 분석과 개선 내역은 [docs/UI-REVIEW.md](docs/UI-REVIEW.md)를 참고하세요.

개발 레퍼런스: 사용자가 지정한 [y3ssam/gacha-game](https://github.com/y3ssam/gacha-game)의 UI·에셋 분류·생성 프롬프트 자료를 참고합니다. 변경은 이 `gacha-ai` 저장소에 적용합니다.

게임 메뉴는 하단에 있으며, 캐릭터 상세는 항목별로 나뉩니다. 설정의 **AI 연결 / 저장·백업 / 이미지 기록**에서 해당 기능을 이용할 수 있습니다. 소환 화면은 왼쪽에서 종류를 고르고, 배너 아래에서 보장 수치와 소환 비용을 확인합니다.

## gacha-game UI·이미지 이식

`gacha-game`을 단순 참고하는 대신 원본 구성요소 CSS와 PNG 11장을 저장소에 실제로 복사했습니다. 던전 선택·난도·전투, 장비 목록·선택·강화·장착은 이 게임 엔진과 연결되어 진행을 저장합니다. 기본 세계·캐릭터·내장 스토리와 기존 기본 삽화는 제거했습니다. 이미지가 없는 AI 캐릭터는 중립적인 미생성 표시를 사용합니다.

가져온 파일·해시·기능 연결 및 범위는 [docs/REFERENCE-IMPORT.md](docs/REFERENCE-IMPORT.md)에 기록했습니다.
