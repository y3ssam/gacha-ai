# 기간제 이벤트·주기 콘텐츠·의상 시스템

## 기간제 이벤트

각 세계 생성 시점을 기준으로 14일마다 새 시즌이 시작됩니다. 빙고·시즌 패스·이벤트 던전·교환소·보급 뽑기를 한 이벤트 메뉴에서 제공합니다. 시즌별 진행과 재화는 독립적입니다.

진행 종료 후 3일은 기존 보상 수령과 교환/보급 뽑기만 가능합니다. 이 기간에는 기존 시즌 던전을 시작하거나 미션을 추가 진행할 수 없습니다. 새 시즌은 이전 정산 기간과 동시에 시작됩니다. 지난 시즌 기록과 수령 여부는 저장합니다. 새 시즌에 지난 활동이 소급 반영되지는 않습니다.

| 시스템 | 규칙 |
| --- | --- |
| 빙고 | 3×3. 전투·캐릭터 소환·강화·이벤트 던전·일일 보상·행동력·장비 강화·시나리오·상점 구매 미션 |
| 칸 보상 | 각 이벤트 재화 40 + 골드 500, 1회 수령 |
| 줄 보상 | 가로/세로/대각선 총 8줄. 각 성정석 80 + 재화 100, 1회 수령 |
| 시즌 패스 | 일일/주간/시즌 미션을 달성하고 XP 수령. 100 XP마다 1레벨, 최대 20레벨. 별도 유료 트랙 없음 |
| 패스 보상 | 골드·기록·정수·재화·성정석·캐릭터 소환권·의상 소환권 |
| 이벤트 던전 | 초/중/상급 Lv.1/20/40. 행동력 15 소비. 승리 시 재화 60/120/180과 기본 전투 보상 |
| 전투 중 종료 | 기존 전투는 마칠 수 있지만 시즌 종료 뒤 정산하면 이벤트 재화는 지급하지 않음 |
| 교환소 | 골드·기록·정수·성정석·캐릭터 소환권·의상권·5성 장비. 시즌별 구매 제한 |
| 보급 뽑기 | 50 재화/회. 골드 1,500 45% / 기록 10 25% / 정수 3 15% / 성정석 80 10% / 캐릭터 소환권 1 5% |

`src/events.js`에 미션·가격·확률·지급 규칙을 정의합니다. AI는 이벤트 경제를 변경하지 않습니다. 소환권은 해당 캐릭터/의상 소환에서 먼저 소비하고 부족한 횟수만 성정석으로 결제합니다. 기간 종료 후에도 이미 받은 소환권은 보관됩니다.

## 플레이어 레벨

캐릭터 레벨과 별개입니다. 승리마다 `60 + 적 레벨×2`, 시나리오 최초 승리 추가 40 XP, 일일 보상 60 XP를 받습니다. 현재 레벨 L에서 다음 레벨에 필요한 XP는 `100+L×20`, 최대 Lv.100입니다. Lv.5까지 누적 600 XP가 필요합니다.

이전 저장에는 기존 승리 횟수×60 + 완료한 시나리오 수×40을 초기 계정 XP로 반영합니다. 기존 캐릭터·재화·소환 보장·일러스트를 보존합니다.

## 신규 캐릭터·배너

- 세계 생성 시 초기 8명과 배너를 생성합니다.
- 세계 생성 시점부터 7일마다 새 풀의 생성 대상이 됩니다.
- 매 주기 신규 5/4/3성 각 1명을 추가합니다. 역할 조합은 주기별로 순환합니다.
- 캐릭터 설정과 배너 검증이 모두 성공해야 도감과 소환 풀을 변경합니다. 실패 시 현재 배너를 유지합니다.
- 새 캐릭터는 일반 풀에도 추가됩니다. 현재 픽업은 신규 5성입니다. 일반/픽업의 기존 천장과 픽업 확정 보장은 이월됩니다.
- 신규 캐릭터는 미독 챕터의 합류 후보에 등록됩니다. 저장된 과거 시나리오는 변경하지 않습니다.
- 자동 갱신은 열린 게임·연결된 Vertex 환경에서만 실행합니다. 지침 화면에서 끌 수 있고 소환 화면에서 수동 재시도할 수 있습니다.
- 닫힌 앱에서 백그라운드 서버가 계속 생성하는 구조가 아닙니다. 오프라인 동안 놓친 주기는 현재 주기 1개로 합칩니다.
- 도감 상한 300명. 신규 3명을 더 넣을 수 없으면 주기 자동 생성을 멈춥니다.

## 의상 가챠

1. 플레이어 Lv.5 도달 시 보유 캐릭터 중 2~3명을 중복 없이 추첨하여 고정합니다. 이후 획득한 캐릭터 때문에 같은 풀을 다시 추첨하지 않습니다.
2. 첫 해금부터 14일 간격으로 새 의상 풀이 시작됩니다. 지난 풀의 획득 의상은 영구 보관됩니다.
3. **소환 → 의상 소환**에서 의상 설정(Vertex)과 추가 일러스트(NAI)를 생성합니다. 대상 캐릭터당 1개입니다.
4. 의상 설정과 모든 이미지가 준비된 뒤에만 해당 풀에서 소환할 수 있습니다. 실패 시 성공한 이미지는 보관하고 누락 이미지만 재시도합니다.
5. 1회 성정석 120 또는 의상권 1장. 추가 일러스트 기본 10%, 10회 이내 미획득 일러스트 보장. 나머지는 골드 500(49.5%) / 기록 5(27%) / 정수 2(13.5%).
6. 일러스트가 당첨되면 해당 풀의 미획득 일러스트 중 균등하게 고릅니다. 중복 일러스트는 나오지 않습니다. 모든 일러스트를 얻으면 소환이 멈춥니다.
7. 10회 소환은 10회 전체 실행 예산이 있어야 시작하지만, 도중에 전부 획득하면 실제 실행 횟수만 차감합니다. 자금 부족 상태에서 난수 결과만 무료로 다시 뽑는 것을 방지합니다.
8. **캐릭터 상세 → 보유 일러스트**에서 기본 이미지 또는 획득한 추가 이미지를 선택합니다. 로비·편성·캐릭터 카드·전투 초상에 적용되며 스탯은 바뀌지 않습니다.

기간·보장·대상·보유·선택 이미지·생성 중간 상태는 모두 세계별 로컬 저장과 JSON 백업에 포함됩니다. API 키/토큰은 포함되지 않습니다.
