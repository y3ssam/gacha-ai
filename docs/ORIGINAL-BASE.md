## 검토 기준

세 가지 접근 중 CSS만 복사는 실제 화면·동작을 보존하지 못하고, 기존 gacha-ai에 컴포넌트를 맞추면 4인/6인·3화/10화·메뉴 구조가 충돌합니다. 최종 구현은 원본 게임 전체를 기반으로 삼고 그 데이터·동작을 완성하는 방식입니다.

반론 점검에서 (1) 원본처럼 보이기만 하는지, (2) 미리보기 수치가 실제 보상인 것처럼 남는지, (3) 새로고침·실패 재시도로 진행이 달라지는지를 확인했습니다. 전체 CSS 해시/전체 원본 에셋, 실제 엔진·원본 DOM 검증, 단계 저장·보상 멱등성·배속 타이머 회귀 검사로 대조했습니다.

## 실행 검증과 범위

- npm run check, npm test. 원본 DPAPI 테스트는 같은 Windows 사용자 권한에서 실행합니다.
- 실제 브라우저에서 원본 UI로 v2 테스트 저장을 가져온 뒤 레벨업(골드 1,000 차감), 원본 대화/선택/6인 편성/브리핑/실제 스킬/배속/새로고침 복원을 확인했습니다. 자동 전투 승리 후 골드 10,000·다이아 80 지급과 원본 던전 화면 복귀도 확인했습니다. 테스트 데이터는 test/ 또는 작업용 파일에만 있으며 새 게임에 제공하지 않습니다.
- 원본 Windows DPAPI 암호화 저장/재시작 복원과 모의 Vertex/NovelAI 요청 검사는 통과합니다. 실제 API 계정의 유료 생성은 실행하지 않았습니다.
- 기존 gacha-ai v1 DB를 삭제하지 않습니다. 새 6인 게임으로 자동 변환하지 않으며 v2 형식을 별도로 사용합니다.
- 장기 경제/난도 밸런스, 실제 생성 이미지 품질, 기기 전체 조합을 검증한 제품 출시 보증은 아닙니다. Pages 설정이나 공개 배포는 실행하지 않았습니다.
