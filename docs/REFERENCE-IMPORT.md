# gacha-game UI·이미지 실제 이식 — 2026-10-17

사용자가 지정한 [gacha-game](https://github.com/y3ssam/gacha-game/tree/6ae30d1c1f44edd5b9ad85f5dcb1f21d88d3d716)의 UI와 이미지를 `gacha-ai`로 복사하고 게임 엔진에 연결했습니다. 이전의 스타일 참고 패치를 대체하는 후속 작업입니다. 원본 저장소는 수정하지 않았습니다.

## 실제 가져온 자료

- `src/reference.css`: 원본 `index.html`에서 사용하는 구성요소의 CSS 선언 312개를 복사했습니다. 테마 변수와 상단 자원·하단 메뉴, 세계 생성 안내, 캐릭터 카드/상세, 소환, 던전, 장비·가방, 연결 입력 구성요소입니다. 선택자에 `.reference-ui` 범위를 추가했습니다. 원본의 미리보기 전용·창 너비 미디어 쿼리는 제외하고 1600×900 게임 프레임에 맞추었습니다.
- `src/reference-ui.js`: 원본 컴포넌트의 DOM 구조와 클래스를 바탕으로 데이터·버튼을 이 게임 엔진에 연결하는 어댑터입니다. 원본 정적 미리보기 인물이나 가짜 재화를 가져오지 않습니다.
- `src/integration.css`: 원본 UI를 1600×900 프레임과 현재 엔진의 메뉴/슬롯 수에 맞추는 레이아웃 조정입니다.
- `assets/reference/`: 원본 PNG 11장을 파일 내용 그대로 복사했습니다. 원본 파일 SHA와 업로드 blob SHA가 일치합니다. 파일별 SHA-256·원본 경로는 `provenance.json`에 기록했습니다.
- 각 에셋 폴더의 `source-manifest.json`은 원본 분류·기획을 보존하는 참고 자료입니다. 거기에 나열된 모든 원본 이미지나 밸런스를 이번 실행에 포함한다는 뜻은 아닙니다.

## 연결한 실제 게임 동작

| UI | 엔진/저장 동작 |
| --- | --- |
| 새 게임 | 빈 세계 슬롯 → AI 연결 → 지침 → 단계별 세계/등장인물/적/챕터/배너 생성 |
| 던전 선택 | 원본 세로 이미지 카드 → 선택 던전 상세와 난도 3개. 선택만으로 행동력 차감 없음 |
| 던전 시작 | 기존 `startBattle` 호출, 행동력 15 차감, 실제 턴제 전투·자동 전투·승리 보상·이벤트 미션 진행 |
| 가방 | 실제 획득 장비 목록 → 선택 상세 → 골드 소모 강화 → 캐릭터 선택 후 장착. 인스턴스 중복 착용 금지 유지 |
| 캐릭터 카드/상세 | AI 생성 도감·실제 보유/레벨, 성장·스킬·장비·프로필·영구 소유 일러스트·생성 설정 |
| 소환 | 실제 재화/소환권 차감, 확률·보장·중복 조각·획득 저장. Vertex 주기 풀과 의상 가챠 유지 |
| 나머지 화면 | 시나리오·파티·이벤트·상점·업적·AI 설정의 기존 작동 시스템을 유지 |

PNG는 런타임에 다른 GitHub 주소에서 가져오지 않고 게임과 함께 제공됩니다. 로컬 서버는 `assets/reference/{dungeons,equipment,materials}/*.png`만 추가로 허용하며, 임의 디렉터리나 키 파일은 열지 않습니다. Pages의 기존 `src`/`assets` 복사 설정에도 포함됩니다.

## 기본 제공 게임 제거

- `createGame()`은 항상 빈 도감·빈 파티·빈 장비·빈 스토리로 시작합니다. 빈 생성 화면 이전에 게임 메뉴로 진입하지 않습니다.
- 기본 세계로 시작 버튼, 기본 캐릭터 4명, 고정 세계관/챕터 제목, 내장 예시 스토리 fallback을 제거했습니다.
- 이전 기본 삽화인 `lobby.webp`, `characters.webp`, 4개 `dungeon-*.webp`를 삭제했습니다.
- 미생성 캐릭터 이미지는 중립 실루엣입니다. 다른 예제 캐릭터 그림을 대신 표시하지 않습니다.
- 신규 세계·새 시나리오는 Vertex 연결이 필요합니다. 생성한 내용은 브라우저에 저장되어 재사용됩니다. NAI 이미지는 플레이어의 연결/생성 설정에 따라 호출합니다.
- 기존 브라우저 저장을 삭제하지 않습니다. 예전 demo 저장은 자동 진입 대상에서 제외하지만 저장·백업 화면에서 수동 접근할 수 있습니다.
- 테스트에 필요한 옛 예제 데이터는 `tests/fixtures/`로만 옮겼으며 배포 대상 `src`/`assets`에는 포함하지 않습니다.

## 검증

- `npm run check`, `npm test` **106개 통과**.
- 원본 PNG 11장 해시 및 크기/투명 PNG 형식, 새 게임 무인물/무장비 상태, 실 던전 차감 및 장비 강화·장착 연결, 로컬 서버의 PNG 제공과 임의 경로 차단을 검사했습니다.
- 실제 Vertex/NAI 유료 호출과 실제 브라우저 시각·클릭 검증은 미수행입니다. 현재 환경에서 Sites 지침이 요구하는 control-browser 기능이 제공되지 않아 별도 브라우저를 설치하거나 임의 경로로 대체하지 않았습니다.
- GitHub Pages 배포는 실행하지 않았습니다. 결과는 `gacha-ai/main`의 소스·에셋 패치입니다.
