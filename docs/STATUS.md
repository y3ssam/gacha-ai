## 검증

- `npm run check`: 통과.
- `npm test`: 33개 통과.
- 화면 검사는 최소 DOM 환경에서 각 화면의 렌더 함수가 예외 없이 실행되는지 확인한 코드 검사입니다. 실제 브라우저의 시각·입력·IndexedDB 통합 검사와 같지 않습니다.
- 마지막 챕터 보스 Lv.49에 기본 4인 파티로 100회씩 자동 전투 시뮬레이션: 파티 Lv.1/20은 0승, Lv.40/60은 100승. 해당 레벨의 돌파와 최대 가능 스킬 레벨 적용, 장비/각성 없음. 이 결과는 특정 기본 편성의 초기 난도 확인이며 전체 조합의 밸런스 증명이 아닙니다.
- 실제 API 계정/키는 전달받지 않았으므로 유료 생성·계정별 권한·할당량·실제 이미지 일관성은 검증하지 않았습니다.
- 이 실행 환경에서 지원되는 브라우저 제어 기능이 없어 PC/모바일 실제 화면 검증은 수행하지 않았습니다.
- Pages 활성화/공개 배포는 사용자가 추후 설정하겠다고 한 범위대로 실행하지 않습니다.

## 다음 실제 사용 시 확인할 항목

1. PC에서 `npm start`, 기본 세계 플레이, 새로고침 후 진행 유지, 백업 내보내기/가져오기.
2. 설정에서 실계정 연결 후 빈 슬롯에 세계 지침을 입력하고 첫 세계 생성.
3. 첫 시나리오 생성, 선택 후 다음 화에 반영되는지, 실패한 NAI 작업 재시도.
4. Pages를 켠 뒤 로컬 연결 프로그램 접근 허용 및 저장 파일 이동.
5. 장기 플레이 후 경제·난도·반복 보상 조정.

## 의도한 범위

일관된 전투 규칙을 가진 플레이 가능한 초기 버전입니다. AI 스킬은 검증된 고정 효과 템플릿을 사용하고 이름/설정이 달라집니다. 사용자 AI 계정의 모델 성능이나 설정 준수 여부를 엔진이 의미론적으로 완전히 보장할 수는 없습니다. 모바일에서 로컬 연결 프로그램 없이 JSON 키를 직접 사용하는 방식, 계정/멀티플레이, 클라우드 세이브는 구현하지 않았습니다.
