# UI 분석 및 1600×900 패치 — 2026-10-17

## 비교한 실제 게임 화면

게임 화면을 검색해 로비와 모집 UI의 배치 관계를 비교했습니다. 게임 자산은 가져오지 않았습니다. 아래 화면에서 관찰한 배치를 이 게임에 맞춰 재해석한 것이며, 해당 게임의 최신 버전 전체 UI를 검증한 것은 아닙니다.

- [명일방주 로비 화면](https://arknights.wiki.gg/wiki/Home_Screen/UI): 중앙의 캐릭터, 상단 자원, 가장자리 기능 메뉴, 별도 이벤트 진입 영역. 검색에서 확인한 Day/Silverfrost 화면을 참고했습니다. 원문 페이지는 조회 시 403으로 열리지 않았습니다.
- [블루 아카이브 모집 화면](https://gamesink.net/blue-archive/articles/147): 배너와 모집 유형 탭, 하단의 1회/10회 행동, 확률 정보 진입. 초기 버전 스크린샷의 정보 배치를 참고했습니다. 이 자료의 과거 확률 수치를 본 게임에 적용하지 않습니다.
- [넥슨 커뮤니티 모집 화면 사례](https://forum.nexon.com/bluearchive/board_view?allBoard=1&board=1070&thread=2720817): 픽업 대상·재화·모집 행동이 구분되는 구성을 추가로 비교했습니다.

## 코드에서 확인한 문제와 수정

| 문제 | 원인 | 수정 |
| --- | --- | --- |
| PC에서 웹 문서처럼 화면이 계속 늘어남 | shell/layout/home이 각각 `100dvh`, 최소 높이에 의존 | 1600×900 논리 화면, 72px 상단바 + 828px 본문 고정 |
| 작은 화면에서 전혀 다른 메뉴 배치와 높이 규칙 충돌 | 900/600px 미디어 쿼리와 추가한 sticky/fixed 메뉴 규칙 | 게임 레이아웃은 동일하게 유지하고 가로·세로 중 작은 배율로 전체 축소 |
| 외부 여백까지 게임 배경이 채워짐 | body 배경과 shell 배경이 전체 창에 적용 | 바깥은 밝은 회색 `#f3f4f6`, 게임 프레임만 중앙 표시 |
| 캐릭터가 가로/세로로 눌려 보임 | `background-size:400% 100%`가 각 슬롯의 비율에 시트를 강제 변형 | 1774×887 시트의 각 443.5×887 셀을 SVG viewBox로 분리하고 원래 1:2 비율 유지 |
| 의상·초상·CG의 일부가 잘림 | 슬롯마다 `cover` | `contain`으로 전체 그림 표시. 비율 차이의 여백은 어두운 배경으로 처리 |
| 생성된 배너 위에 다른 초상 중복 표시 | 배너 배경과 banner-art를 동시에 렌더 | 생성 배너가 있으면 별도 캐릭터 초상 생략 |
| 로비 캐릭터가 편성 패널에 밀리고 큰 빈칸 발생 | 오른쪽 열에 초상과 편성 패널을 수직 누적 | 왼쪽 세계/시나리오, 중앙 일러스트, 오른쪽 소환/이벤트/편성의 독립 3열 |
| 긴 세계관이 로비의 행동 버튼을 밀어냄 | 세계관 전체를 항상 출력 | 펼칠 수 있는 기록 영역으로 변경, 긴 본문은 해당 영역 스크롤 |
| 전투 명령이 화면 아래로 밀림 | 적 340px + 아군 초상 145px + 긴 로그 | 적 영역 258px, 아군 초상 118px, 로그 92px로 조정 |
| 모달·로딩·알림의 기준 좌표가 서로 다름 | body fixed, viewport 크기 사용 | 로딩과 알림은 stage 내부, native dialog는 같은 배율/중심으로 표시. backdrop은 프레임 범위만 덮음 |
| 보상 수령 등에서 목록 위치가 맨 위로 이동 | 모든 render에서 main 교체 | 같은 화면의 세로 스크롤 및 일치하는 버튼의 키보드 포커스 복원, 페이지 변경 시 스크롤 초기화 |
| 기본 일러스트/의상 표시 경로 중복 | gallery의 별도 background 구현 | 공통 portrait renderer 사용, 기본 이미지 옵션은 현재 의상 선택과 독립 |

## 프레임 규칙

`scale = min(1, viewportWidth / 1600, viewportHeight / 900)`

| 브라우저 표시 영역 | 실제 프레임 | 배율 |
| --- | --- | --- |
| 1920×1080 | 1600×900 | 1 |
| 1600×900 | 1600×900 | 1 |
| 1280×720 | 1280×720 | 0.8 |
| 1920×720 | 1280×720 | 0.8 |
| 800×450 | 800×450 | 0.5 |

창이 작아져도 이미지와 버튼의 상대 비율은 유지합니다. 전체 페이지 스크롤 대신 본문/모달의 내부 스크롤을 사용합니다. 메뉴 12개는 828px 높이에 배치되며 필요 시 메뉴 영역 자체를 스크롤할 수 있습니다. 패딩 16/20/24/32px, 일반 버튼 최소 높이 44px, 주요 행동 48px를 **1600×900 논리 좌표 기준**으로 적용했습니다. 축소한 모바일에서 실제 터치 영역까지 44px를 보장하는 방식은 아니므로 휴대폰에서는 가로 방향을 권장합니다.

상세·갤러리에서는 그림 전체를 보존하므로 비율 차이에 따라 여백이 생깁니다. 배경/던전과 가로 배너 배경은 장면을 채우는 `cover`를 유지하며, 전체 그림을 읽는 CG/초상/의상은 `contain`을 사용합니다. 원본 파일에 이미 합쳐져 있거나 잘려 있는 인물은 이 패치로 복구할 수 없습니다.
