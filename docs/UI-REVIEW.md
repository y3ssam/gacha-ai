# UI 분석 및 1600×900 패치 — 2026-10-17

## 비교한 실제 게임 화면

게임 화면을 검색해 로비와 모집 UI의 배치 관계를 비교했습니다. 게임 자산은 가져오지 않았습니다. 아래 화면에서 관찰한 배치를 이 게임에 맞춰 재해석한 것이며, 해당 게임의 최신 버전 전체 UI를 검증한 것은 아닙니다.

- [명일방주 로비 화면](https://arknights.wiki.gg/wiki/Home_Screen/UI): 중앙의 캐릭터, 상단 자원, 가장자리 기능 메뉴, 별도 이벤트 진입 영역. 검색에서 확인한 Day/Silverfrost 화면을 참고했습니다. 원문 페이지는 조회 시 403으로 열리지 않았습니다.
- [블루 아카이브 모집 화면](https://gamesink.net/blue-archive/articles/147): 배너와 모집 유형 탭, 하단의 1회/10회 행동, 확률 정보 진입. 초기 버전 스크린샷의 정보 배치를 참고했습니다. 이 자료의 과거 확률 수치를 본 게임에 적용하지 않습니다.
- [넥슨 커뮤니티 모집 화면 사례](https://forum.nexon.com/bluearchive/board_view?allBoard=1&board=1070&thread=2720817): 픽업 대상·재화·모집 행동이 구분되는 구성을 추가로 비교했습니다.

## 프레임 규칙

`scale = min(1, viewportWidth / 1600, viewportHeight / 900)`

| 브라우저 표시 영역 | 실제 프레임 | 배율 |
| --- | --- | --- |
| 1920×1080 | 1600×900 | 1 |
| 1600×900 | 1600×900 | 1 |
| 1280×720 | 1280×720 | 0.8 |
| 1920×720 | 1280×720 | 0.8 |
| 800×450 | 800×450 | 0.5 |

창이 작아져도 이미지와 버튼의 상대 비율은 유지합니다. 전체 페이지 스크롤 대신 본문/모달의 내부 스크롤을 사용합니다. 메뉴 12개는 828px 높이에 배치되며 필요 시 메뉴 영역 자체를 스크롤할 수 있습니다. 패딩 16/20/24/32px, 일반 버튼 최소 높이 44px, 주요 행동 48px를 **1600×900 논리 좌표 기준**으로 적용했습니다. 축소한 모바일에서 실제 터치 영역까지 44px를 보장하는 방식은 아니므로 휴대폰에서는 가로 방향을 권장합니다.

상세·갤러리에서는 그림 전체를 보존하므로 비율 차이에 따라 여백이 생깁니다. 배경/던전과 가로 배너 배경은 장면을 채우는 `cover`를 유지하며, 전체 그림을 읽는 CG/초상/의상은 `contain`을 사용합니다. 원본 파일에 이미 합쳐져 있거나 잘려 있는 인물은 이 패치로 복구할 수 없습니다.
